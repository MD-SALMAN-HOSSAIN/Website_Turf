# Website Turf

A modern turf booking and sports ground website designed to help users discover, compare, and reserve premium turf spaces for football, swimming, and other outdoor activities.

## About This Website

This website is built to make turf booking simple and enjoyable. It gives users a clean place to explore available grounds, view turf details, and quickly choose a location that matches their needs.

## Website Style

The design is simple, fresh, and vibrant, using a sporty color palette to keep the experience energetic and professional. It focuses on quick access to turf information, smooth navigation, and a strong call-to-action for customers.

### Example of the Experience

1. User opens the homepage and sees featured turfs.
2. They browse available grounds and check rates.
3. They choose a turf based on size, sport, and location.
4. They confirm the booking and enjoy a smooth booking process.
